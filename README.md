## 🧠 About Me

I'm a Computer Science undergraduate interested in cybersecurity, cryptography, and secure systems engineering. I enjoy understanding how systems work at a low level, exploring security weaknesses, and turning what I learn into practical projects.

My current interests include:

- **Post-Quantum Cryptography (PQC):** learning about quantum-resistant algorithms and the impact of quantum computing on RSA, Diffie–Hellman, and elliptic-curve cryptography.
- **Cybersecurity:** security monitoring, networking, vulnerability analysis, and defensive security.
- **Secure Systems:** implementing and evaluating cryptographic components and security-focused network designs.
- **Programming:** using C/C++ and Python to understand algorithms and build practical tools.
